Methodology

  • The goal of this study's quantitative, data-driven research strategy is to develop a machine learning-based system for analyzing the performance of netball players. In order to offer an objective, real-time analysis of player performance across three crucial functional areas—ball handling, attacking, and defending skills, the main goal is to build and create a system that combines posture estimation with machine learning models. The purpose of this study is to overcome the limitations of conventional netball evaluation techniques, which mostly rely on subjective judgements and fall short in capturing the subtler aspects of player performance.
  • In order to accomplish this, the study tracks player motions in training and game situations using pose estimation methods like Media Pipe. To produce useful insights for coaches and players, the gathered data is analyzed using feature engineering approaches to extract pertinent performance indicators. These measurements are then assessed using machine learning models.
  • Real-time feedback is included into the system to enable dynamic modifications throughout training sessions and games. Additionally, the system incorporates biological data, such heart rate and tiredness levels, to track players' physical health, improving injury avoidance tactics and performance. The technique offers a thorough, impartial way to assess netball performance by using technology and sports statistics.
